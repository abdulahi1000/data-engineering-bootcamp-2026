# Data Engineering Bootcamp 2026

This repository documents my progress through the Core Data Engineers Bootcamp 3.0.

My background has mainly involved analytics, reporting, dashboards, and business intelligence. I am using this programme to deepen my understanding of the engineering layer behind the data I work with.

Rather than waiting until the end of the programme to document what I have learned, I am building this repository progressively as I move through each topic.

## Progress So Far

### 01. Data Engineering Fundamentals
Understanding the role of data engineering, operational vs analytical systems, data pipelines, and the broader data architecture.

### 02. Linux
Working with the Linux command line, files and directories, users and groups, permissions, environment variables, redirection, search, and command chaining.

## How I Am Documenting the Journey

For each topic, I will capture:

- What I learned
- What I practised
- What challenged me
- What clicked for me
- How it connects to my previous experience
- Screenshots and other proof of work

This repository will continue to grow as I progress through the programme.
