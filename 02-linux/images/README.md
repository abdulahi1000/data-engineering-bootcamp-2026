## Before publishing

Review screenshots for information that does not need to be public, especially:

- device or corporate hostnames
- personal usernames or filesystem paths
- company names
- passwords
- API keys
- tokens
- connection strings
- private data

The current WSL screenshots show a device hostname in the terminal prompt. Consider masking that hostname before committing the images to a public repository.
